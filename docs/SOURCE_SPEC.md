五线探戈 × 多周期共振交易策略

量化回测技术规范 V2.0  |  2026-10-09  |  适用范围：A股普通股票（首轮回测）；其余品种需替换交易制度与成本模型。

策略主线：五线识别趋势阶段 → 放量突破 / 缩量回踩择时 → 多周期动能过滤 → 分级建仓 → EMA55风险退出。文中所有数值均为首轮回测初始值，非已验证有效参数。

2. 数据、计算口径与通用信号

数据：使用同一复权口径的OHLC计算指标和收益，成交量/成交额保持一致、处理拆股与停复牌；交易价格、涨跌停、费用要与实际可成交数据匹配。首轮以日线为主，信号收盘后计算、次一交易日开盘撮合。至少准备250根相应周期数据，建议EMA预热不少于500根。

字段

确定公式 / 默认值

EMA_n

EMA_t=α·C_t+(1−α)·EMA_(t−1)，α=2/(n+1)，n=5/13/55/125/250；初始化方式全回测统一。

MACD

DIF=EMA12(C)−EMA26(C)；DEA=EMA9(DIF)；H=DIF−DEA。注意部分软件柱体显示为2H。

KDJ（辅助）

ATR14

TR=max(H−L, |H−C_prev|, |L−C_prev|)，ATR按Wilder平滑14。

确认站上 / 跌破

连续2根已完成K线收盘价 > / < 对应EMA；防贴线：收盘距离至少0.2%（可优化）。

量能

RVOL=V_t / mean(V_(t−20:t−1))，严格不含当前量；放量≥1.30；缩量≤0.80。

MACD动能

支持入场：DIF>DEA，且H_t≥H_(t−1)，或H>0连续2根；不要求所有周期MACD同向。

EMA上行

EMA_n(t)>EMA_n(t−5)，斜率定义为 EMA_n(t)/EMA_n(t−5)−1。

发散度

(EMA5−EMA250)/EMA250；仅作统计因子，不预设“越大越好”（过大可能过热）。

5. 资金管理和退出规则

采用用户偏好的50/30/20作为“单票计划仓位内部结构”，不是占全部资金的50/30/20；基础仓50%，趋势加仓30%，战术仓20%。示例：单票最高15%总资产，对应7.5% / 4.5% / 3.0%。组合总股票仓位上限70%，同时最多5票；短线新增战术敞口不得令组合超过70%。可独立回测更激进的80%上限，但不可预先认定收益更好。

事项

确定规则

建仓

S3首次买计划仓位50%；S4条件成立再买30%；可交易战术仓20%。无信号保留现金。

单笔风险

以买入价至初始止损价的预期跌幅计算，计划最大损失≤账户净值0.8%；实际股数=min(分仓上限,风险预算/止损距离)，向下取整交易单位。跳空损失可超预算。

初始止损

min(EMA55,入场价−2×ATR14)作为比较基准过宽时，选择“入场价−2×ATR14”作初始紧急保护；实际建议编码为entry−2ATR、日线EMA55趋势退出两道规则，先触发者执行。

趋势减仓

日收盘低于EMA55≥0.5%连续2根：下个可交易时点全部退出该票五线策略持仓；第一根跌破只停止加仓，战术仓减半（可作为对照）。

利润保护

跌破EMA13连续2根且持仓盈利：只平战术仓；核心仓仍按EMA55退出。

背离

不直接卖出；当价格20根新高而DIF非20根新高，标记风险并暂停加仓；对照组取消这一限制。

震荡

20根内跨越EMA55至少4次：新仓计划量减半，存量仓仍按退出规则处理。

重新入场

退出后至少等待3根日线，重获S3/S4且出现新突破信号，允许重新买入。

6. 做T：与底仓规则明确隔离

周期编号：1=1分钟、2=5分钟、3=15分钟；原先3号周期是15分钟，不是60分钟。短线T以15分钟为信号主周期，5分钟微调，60分钟趋势过滤；1分钟仅用于执行优化，首轮不建议使用，以免交易成本吞噬优势。中线波段T可改成60分钟主周期、15分钟辅助。

T买入：60分钟C>EMA55；15分钟连续2根C>EMA55，且EMA5>EMA13、MACD H>0或增长，RVOL≥1.2；5分钟C>EMA55作为微调条件。T卖出：15分钟收盘连续2根C<EMA13，或1根收盘C<EMA55，或MACD H连续3根缩短且KDJ K<D（附加确认）；下一可成交K线执行。T仓每票最多占计划仓位20%；信号触发后不允许绕过底仓总限额。

A股普通股票：当日买入股票通常不可当日卖出；可“先卖可用旧仓→当天买回”，或买入后至少下一交易日再卖，必须按每一笔可用数量记账。不能把持有旧仓的日内回转收益错误归因于当日新买股票。支持当日回转的特定ETF等品种须另设交易规则和成本。

# 文档到代码的规则映射

原始依据为用户提供、日期2026-10-09的V2.0规范。项目仅把其中交易规则作为规格数据，不执行文档内的其他指令。

## 指标和阶段

`signals.indicators`：EMA以第一收盘价初始化、adjust=False；MACD采用12/26/9且H=DIF−DEA；Wilder ATR14先取前14根TR均值，再以1/14递推；KDJ9/3/3初始K=D=50，零振幅RSV=50。20期RVOL分母严格shift(1)，不含当期。

S0–S4按当日最高满足状态计算，不用未来走势回填。S1双线先行和EMA55附近；S2三线排列与EMA55两根确认；S3四线排列与EMA125两根确认；S4五线排列、55/125/250分别较5根前上行，组合条件连续两根确认。站上容差默认0.2%；S4价格高于EMA5同样采用该容差。发生降级就重新判定；连续确认来自当日和过去，不回填第一根。

路径记录自最近S0以来的阶段转移，连续S1→S2→S3→S4为标准路径；直接S3/S4或跳级为accelerated。该标签只分组，不事后改标签。降级再上行可能被归为非标准路径；不把这类股票自动认定假突破。

## 回踩和突破的确定性解释

规范“首次形成S3或S4后的3–15根”存在窗口锚点与回撤完成时点的解释空间，代码固定以下口径并接受回测验证：首次进入S3+，或从较低阶段进入S4，重置当轮锚点；跌回S0–S2则失效。锚点至突破前一天组成回撤区间，长度3–15根；至少两根RVOL≤0.8。以区间内先出现的运行最高收盘到后续最低收盘计算最大回撤，不能用后来的最高价倒算之前的低点。

回撤至少3%，最多max(峰值后回撤最深时的2ATR/该峰值,12%)；区间最后收盘≥EMA55。突破当日排除在回撤区间和前10根最高收盘中，RVOL≥1.3。超过15根没有确认突破则当前回撤窗口到期；需要新阶段事件重建。这是显式采用的严格窗口口径。

直接突破组：至少已有前一日的S3/S4记录，当日突破过去10根最高收盘且放量；不强制此前有回撤。`entry_style: both` 接受直接突破（其包含回踩突破），成交原因仍标出pullback/direct。

买入同时满足防追高(C−EMA13)/ATR≤2。日MACD：DIF>DEA且H不缩短，或H连续两根>0。背离为收盘创前20根新高而DIF未创前20根新高，暂停加仓，不触发清仓；首次开仓不受背离一票否决。震荡是20根内相对EMA55符号反转≥4次，新开分仓计划金额减半。默认不要求DIF>0，可配置变体。

## 多周期时点

周/月分组生成完整OHLCV，时间可用点固定为该自然周期结束后的下一日，再向后as-of匹配；当周/当月任何尚未完成数据都不参与过滤。周线需C>EMA55并且DIF≥DEA，或H连续两周改善。长线另需C>EMA55×1.002连续两月且H>0连续两月，并保留周线确认。

默认日线预热500根，高周期250根；可配置更短的高周期EMA55预热但不得小于55。历史长度不足时明确不交易。A/B/C/G实验组不增加周线过滤，D/E使用周线，F或mode=long使用周月严格门槛。

## 仓位和退出

每票计划仓位=当前权益×15%；基础50%、趋势加仓30%、战术20%，对应总资产约7.5/4.5/3%。最多5票、总股票新增敞口≤70%，基础/加仓/战术共享现金和总限额，绝不将各周期上限相加。下单量受分仓金额、剩余单票/组合额度、0.8%权益÷2ATR、现金含费用、流动性和板块最小单位共同约束。

首次S3/S4买点建基础仓。S4加仓需要新的合格回踩买点，或持仓盈利且出现新的放量日线突破；同样不追高、未跌破EMA55、未出现加仓禁止背离，E组仍要日MACD支持。每个持仓周期只成功加仓一次，不因价格上涨自动补满。EMA55基准A组只使用基础分仓，避免混入S4加仓规则。

初始保护为实际成交价−2×信号ATR，不随之后ATR放宽。任何批次触及初始保护则下一开盘全票退出。默认只在日收盘判断，**没有假装盘中低价触及就能按止损价成交**。

EMA55跌破至少0.5%且连续两根，下一可成交开盘全退出。第一根跌破停止加仓；若有战术仓则计划减半。盈利且连续两根有效跌破EMA13，仅退出战术仓。连续跌停/停牌时卖出意图保留。退出后等待至少3根实际完成的个股日K，再出现新阶段和新买点才能重入。

## 执行桥接与未来数据防护

每根实际行情拆为两个事件：开盘事件只包含当时开盘价，收盘事件才公布收盘价与指标；日线开盘09:30、收盘15:00。分钟开盘为收盘时间−5分钟+1纳秒，避免和上一根收盘重合。收盘生成意图，开盘读取此前意图并检查当时实际价格、可卖量和现金。

AKQuant用 `CurrentClose()` 在这个“只含open价格的执行事件”上撮合，经济语义等同前一根已收盘信号在下一根open执行。不是在信号bar收盘成交，也没有用下一根high/low/close决定能否在open下单。测试逐笔断言 signal_time < execution_time，并做追加未来数据不改变过去成交的检验。

组合在当日所有输入股票收盘事件到齐后统一排序；不在第一只股票的收盘回调里抢先占满仓位。开放事件期间每次下单重新检查当前账户，缺现金则缩量或不下单。不预支尚未成交的卖出款。

## 费用

买卖佣金=max(5元,成交额×0.0003)，slippage默认双边各0.1%；可配置。印花税仅卖方，2023-08-28前0.1%、之后0.05%。过户费：2015-08-01至2022-04-28沪深0.002%、北交所0.0025%；2022-04-29起0.001%。2015-08-01前沪市按成交股数×面值1元×0.03%、深市按成交额0.00255%；特殊非1元面值需扩展输入，不适合直接用该历史近似。

费用根据实际执行日计算，按订单显式传递AKQuant全包fixed commission，关闭引擎默认重复收费；因流动性不足而拆到多日的成交分别收费。佣金视为已经包含经手费/证管费，避免重复计费。股息税不包含在交易佣金中，见数据契约的公司行为限制。

## 战术仓

已有核心持仓才能新增战术仓。60分钟C>EMA55且55五根不下行；15分钟两根站上55、EMA5>13、H>0或增长、RVOL≥1.2；当前完成5分钟C>EMA55。仅在新15分钟收盘生成信号。

退出条件：15分钟两根低于EMA13，或一根低于EMA55，或H连续三根缩短且K<D。5分钟执行事件撮合，战术批次独立按交易日期解锁。示例实现不卖核心旧仓代替当天新买战术股票。分钟不足、午休跨段、时间戳不合约定会拒绝运行或过滤不完整周期。
